# Island Perimeter

This project implements a Python function `island_perimeter(grid)` that calculates the perimeter of a single island represented in a 2D rectangular grid of `0`s (water) and `1`s (land).

## Requirements
- Ubuntu 14.04 LTS / 20.04 LTS
- Python 3 (version 3.4.3 or later)
- PEP 8 style compliance (version 1.7)
- No external or standard library module imports allowed
- All modules and functions documented

## Usage
```bash
chmod +x 0-island_perimeter.py
./0-main.py
```
