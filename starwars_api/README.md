# Star Wars API

This project involves interacting with the Star Wars API (`swapi-api.alx-tools.com`) using Node.js and the `request` module to fetch and display characters from a specified Star Wars movie in exact appearance order.

## Requirements
- Ubuntu 14.04 LTS / 20.04 LTS
- Node.js (version 10.14.x or later)
- `request` module (`npm install request --global`)
- `semistandard` style compliance (`npm install semistandard --global`)

## Usage
```bash
chmod +x 0-starwars_characters.js
./0-starwars_characters.js 3
```
